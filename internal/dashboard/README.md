# Nepal Energy Evidence & Coverage Control Room

This is a localhost-only research operations interface. It is deliberately kept
outside the deployable `wiki/` surface and must not be linked from the public
explorer.

Build and serve it from the repository root:

```bash
make dashboard-build
make dashboard-serve
```

Then open <http://localhost:8765/internal/dashboard/>.

The UI reads `data/processed/dashboard/control-room.json`, which is generated by
`scripts/build_internal_dashboard.py`. Run `make dashboard-check` to verify the
artifact against its current authoritative inputs and execute the generator
contract tests.

The dashboard keeps these scopes separate:

- the full name-keyed hydropower registry;
- the 25 curated technical-specification projects;
- the priority projects with dated events and blockers;
- official DoED reconciliation queues;
- secondary HydroMap comparison queues; and
- governed wiki source metadata.

Regulatory categories are not delivery claims. Publication dates are not
treated as retrieval or freshness dates.
