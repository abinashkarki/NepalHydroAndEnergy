Chameliya–Jauljibi 220 kV Cross-Border Interconnection

The planned far-western Nepal–India interconnection, routed from Chameliya (Darchula, Nepal) to Jauljibi (Pithoragarh, Uttarakhand). This would be the first 220 kV interconnection in the Mahakali basin and the gateway link for any future hydropower expansion in far-western Nepal (including the long-dormant Pancheshwar Multipurpose Project prospect).

Summary

The Chameliya-Jauljibi 220 kV interconnection is a planned far-western Nepal-India cross-border link in the Mahakali basin. The page tracks it as a proposed gateway for future far-west hydropower expansion rather than as a committed or operating interconnection.

Key Facts

Parameter Value
Voltage 220 kV (proposed)
Status Planned
Nepal terminal Chameliya substation (Darchula)
India terminal Jauljibi (Pithoragarh, Uttarakhand)
Primary basin served Mahakali Basin
Driving projects Chameliya Hydropower (30 MW operational), future Mahakali cascade
Interconnection ID chameliya_jauljibi

Significance

  • Only far-western 220 kV cross-border. The existing Tanakpur–Mahendranagar 132 kV link is thermally saturated during monsoon; this is the upgrade path.
  • Unlocks Mahakali Basin. No large hydropower on the Mahakali basin has a viable export route at the current voltage; this line is the precondition for Pancheshwar Multipurpose Project economics.
  • Tri-country gateway. The Jauljibi side lies near the India–Nepal–Tibet trijunction; long-horizon planners have flagged it as a potential node in a broader Himalayan grid.

Limitations & Controversies

  • No construction schedule. Remains in planning documents; neither side has committed capex.
  • Dependent on Pancheshwar Multipurpose Project. The economics of a full 220 kV crossing hinge on the stalled Pancheshwar Multipurpose Project actually delivering.
  • Terrain. Extreme high-altitude alignment through Darchula raises cost per km materially above Terai cross-borders.
