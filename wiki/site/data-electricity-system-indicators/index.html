Summary

This compact, source-linked register collects headline distribution, demand and flexibility observations used by the wiki's core branch pages. It reduces repeated headline values while preserving distinctions such as grid coverage versus reliability and national peak versus system peak.

What This Shows

  • Distribution: grid coverage, aggregate loss, nine administrative-office loss observations and dated enterprise outage evidence.
  • Demand: sales, consumers, sector shares, per-capita use, peak definitions and the electric-cooking baseline.
  • Flexibility: Kulekhani capacity and annual generation.

Coverage / Method

The machine-readable electricity_system_indicators.csv records value, unit, period, geography, scope, source slug, locator, verification date, confidence and caveat.

Caveats

The register contains dated public observations, not interpolated current values, and unlike metrics are not combined into a composite score. It intentionally remains a Working Page because it is not a continuous operating dashboard.
