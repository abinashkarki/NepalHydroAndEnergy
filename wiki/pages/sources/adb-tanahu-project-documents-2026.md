# ADB Tanahu Hydropower Project Documents (2026)

## Summary

ADB's active project page and document register for the 140 MW Tanahu
Hydropower Project. The page provides financing, contracts, audited
statements and current environmental and social monitoring documents.

## Key Findings

- Project status: active; installed capacity: 140 MW storage hydro.
- ADB disclosed FY 2024/25 audited project financial statements in
  January 2026.
- A ninth environmental and social Panel of Experts report was
  disclosed in April 2026.
- The page provides loan utilisation, contract awards, covenant status
  and tender records.
- Original loan closing dates were revised to 30 June 2026.

## Relevance

This is the primary monitoring feed for [[tanahu-hydropower]]. It
supports package, finance and safeguard tracking rather than reliance
on a single overall progress percentage.

## Limitations

The project page's last project-data-sheet update and individual
document dates differ. An overall public progress percentage from
another source should not be attributed to ADB unless it appears in an
ADB document.
