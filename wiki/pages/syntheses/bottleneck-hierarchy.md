# Bottleneck Hierarchy

This page ranks Nepal's energy system bottlenecks by bindingness, showing that the answer changes depending on whether you ask about deep structural cause or immediate practical blocker.

Ranked bottlenecks for Nepal's hydropower system, synthesized across the source notes, data pages, and system-analysis pages. The ranking carries an important nuance: the answer changes depending on whether you ask about deep structural cause or immediate practical blocker.

## In plain language

Nepal's electricity system has many problems, but they are not equally urgent. This page ranks them so that a reader — or a policymaker — knows which constraint to attack first.

The ranking has changed recently. The wiki's 2035 adequacy model shows that **solar can close much of the winter daytime energy gap**, which means the old story — "we just need more storage hydro" — is too simple. The new story is: **solar + storage hydro + batteries + demand-shaping, together**. No single lever does the whole job.

That re-ranking has three consequences you will see below:

1. **Transmission and solar interconnection** is now the #1 immediate blocker, because 5 GW of solar needs grid headroom.
2. **Land for solar** is a new top-tier constraint — without an agrivoltaic framework, Terai solar stalls at ~2 GW.
3. **Storage is still essential, but its job has changed.** It is no longer the only answer to winter energy. It is the answer to the winter *evening peak* — the 6:30 pm moment when solar has set and the lights still need to stay on. That is where the [[budhigandaki]] distinction matters: the model shows Nepal can close the total winter energy gap by 2035 without Budhigandaki, but cannot close the evening peak gap without it or an equivalent firm source. See [[data-winter-deficit-model]].

## The Critical Nuance

- If the question is **"What is the deep structural cause?"** → Storage and timing. The country cannot hold its water, and RoR produces when the system is already long.
- If the question is **"Why doesn't more MW quickly convert into value right now?"** → Transmission and delivery readiness. Generation is racing ahead of grid, and solar will stress substations before reservoirs arrive.
- If the question is **"What changes after the solar audit?"** → Land, interconnection, and BESS join reservoirs as first-tier planning constraints.
- If the question is **"Why can't Nepal fix any of it quickly?"** → Governance and [[buildability]].
- If the question is **"Does Nepal still need Budhigandaki?"** → The 2035 model says: not for total winter energy, but yes for evening firm capacity. The four-lever portfolio (solar + Tanahu + Dudhkoshi + BESS + demand-shaping) closes the Dec–Feb energy gap. At 6:30 pm, a 933 MW shortage remains. Budhigandaki's 1,080 MW effective evening dispatch flips that to surplus. See [[data-winter-deficit-model]] Phase 2 and [[solar-role-in-winter-deficit]].

This is not a contradiction. It is a more serious systems view.

## Why Rankings Differ

| Lens | Single biggest bottleneck | Notable difference |
|----------|-------------------------|-------------------|
| Physical system | Storage (deep) / transmission (immediate) | Separates the seasonal timing problem from the delivery bottleneck |
| Market access | Transmission and trade corridors | Emphasizes that new MW only matters if it reaches buyers at the right time |
| Grid reliability | Storage + grid depth together | Treats dispatchability and network capacity as coupled constraints |
| Economic transformation | Storage, grid, then demand creation | Adds domestic productive use as a third pillar |
| 2035 winter adequacy model | Portfolio execution — no single lever is sufficient | Solar closes daytime energy; storage + BESS + demand-shaping close evening peak; Budhigandaki is the firm-capacity option |
